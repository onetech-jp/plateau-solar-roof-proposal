屋根提案シート 戸田市 / PLATEAU × Solar API

地図上の建物をクリックすると、築年数(PLATEAU)と屋根情報(Solar API)を表示し、太陽光と塗装の概算を出します。

ズーム15以上で建物が表示されます。

単価・係数の設定

JSON を編集して保存するとブラウザに記憶されます(業者ごとの単価表に差し替えてください)。

印刷ダイアログで「PDFとして保存」を選ぶと1枚のPDFになります

ブラウザ用APIキーが設定されていません

プロジェクト直下の .env に GOOGLE_MAPS_BROWSER_KEY(または GOOGLE_MAPS_API_KEY)を書いてサーバーを再起動してください。雛形は .env.example にあります。

キーは Google Cloud Console で「Maps JavaScript API」のみ許可し、HTTPリファラ制限に localhost:5194/* を入れてください。
